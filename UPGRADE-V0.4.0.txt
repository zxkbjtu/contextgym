ContextGym v0.4.0

1. Extract this FLAT package directly into your existing ContextGym directory and overwrite files.
2. Verify:
   node dist/index.js --version
   Expected: 0.4.0
3. Re-run the miner to use the stricter v0.4 proposal classification:
   node dist/index.js mine --proposals-only --top 30
4. Generate review-only drafts:
   node dist/index.js propose --top 20
   or for one repository:
   node dist/index.js propose --project "D:\ZYY\proj\NDFFN" --top 20

Output:
  .contextgym\proposals\proposals.json
  .contextgym\proposals\<project>-<hash>.md

v0.4.0 does NOT edit AGENTS.md or CLAUDE.md.
