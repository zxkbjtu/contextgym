ContextGym v0.5.0 — Context A/B Evaluator

New command:
  contextgym eval

The evaluator requires a live Git repository. Historical findings from a deleted repository can still be mined/proposed with path fallback, but they cannot be replayed in Step 5.

Recommended first run:
  1. Generate a proposal for a repository that still exists.
  2. Create a small task prompt file.
  3. Run eval with --dry-run.
  4. Run one paired smoke test.
  5. Add a deterministic --verify command and use --runs 3 or more before trusting KEEP/REJECT.

The evaluator creates detached temporary Git worktrees. Candidate context is committed only inside the temporary candidate worktree. The original repository is never modified by ContextGym eval.
