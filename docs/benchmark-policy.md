# Benchmark policy

ContextGym benchmark results are intentionally narrow claims.

A valid headline result should disclose:

- repository/task scope;
- number of paired runs;
- success verifier;
- added context size;
- baseline and candidate success rates;
- token, observed-tool, and duration deltas;
- whether the result is a smoke test or an evidence-bearing KEEP/REJECT verdict.

Do not present task-specific gross token leverage as a universal causal multiplier. Do not present best-effort observed tool calls as a complete trace.
