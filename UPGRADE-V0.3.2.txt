ContextGym v0.3.2 — Friction Triage

What changed:
- Filters false read targets such as `tail -n 1` being mistaken for file `1`.
- Avoids PowerShell cmdlets such as ConvertFrom-Json being mistaken for files.
- Collapses the same failing command across multiple repositories into an environment-level finding.
- Classifies findings as repository / environment / workflow / investigate.
- Marks only evidence-backed repository findings as action=propose.
- Adds proposalScore and evidenceLevel.
- Adds `mine --proposals-only` for the next proposal-generation stage.

After copying over v0.3.1:
  node dist/index.js --version
  node dist/index.js mine --top 30
  node dist/index.js mine --proposals-only --top 30

No re-parse is required; v0.3.2 can reuse the v0.3.1 `.contextgym/events.jsonl`.
